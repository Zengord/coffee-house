# Coffee House

Лендинг кофейни с адаптивной версткой, навигацией по секциям и интерактивными элементами.

Проект выполнен по готовому макету для практики верстки лендингов, адаптива и JavaScript-интерактива.

## Live Demo

https://zengord.github.io/coffee-house/

## Возможности

- Адаптивная верстка
- Бургер-меню
- Плавная навигация по секциям
- Секции «О нас», «Меню и цены», «Адреса», «Акции»
- Оптимизированные изображения WebP
- Анимации при скролле
- Использование rem и em единиц

## Стек

- HTML5
- CSS3 / SCSS
- JavaScript
- BEM
- Gulp/Webpack
- GitHub Pages

## Что показывает проект

Проект демонстрирует навыки верстки лендингов, работы с адаптивом, навигацией, изображениями и UI-компонентами.
